# LiveAtlas (Возрождение проекта)

Интерактивный веб-интерфейс для карт Minecraft. Этот репозиторий представляет собой обновленную версию LiveAtlas, в которой устаревшие PHP-скрипты Standalone-режима полностью заменены современным бэкендом на **Node.js/TypeScript**.

Проект поддерживает **Dynmap** по умолчанию, а также имеет встроенную локализацию (русский и английский языки), поддержку S3-совместимых хранилищ для тайлов и совместимость с СУБД MySQL, MariaDB и PostgreSQL.

## Новые возможности этой версии
1. **Node.js/TypeScript Бэкенд:** Полная замена `update.php`, `MySQL_tiles.php`, `login.php` и других PHP-файлов. Бэкенд работает как единый быстрый Express-сервер, раздающий фронтенд и обрабатывающий API.
2. **Встроенная мультиязычность (i18n):** Добавлен переключатель языков (RU/EN) прямо в интерфейсе боковой панели LiveAtlas. Язык сохраняется в браузере.
3. **Поддержка S3-совместимых облачных хранилищ:** Возможность загружать и отдавать тайлы карты напрямую из хранилищ с AWS S3-совместимым API (MinIO, Cloudflare R2, Yandex Object Storage и др.).
4. **Поддержка PostgreSQL и MariaDB:** В дополнение к стандартному MySQL, бэкенд может подключаться к базам данных PostgreSQL и MariaDB для чтения тайлов, конфигураций и работы авторизации.
5. **Совместимость с Dynmap:** Гарантированное сохранение всех функций оригинального Dynmap (чат, маркеры, игроки, время суток, регистрация в игре).

## Настройка бэкенда

Для работы бэкенда создайте файл `.env` в корневой директории проекта.

### Пример конфигурации `.env`:

```ini
# Порт, на котором будет работать веб-сервер LiveAtlas
PORT=8082

# Тип хранилища тайлов: filetree, db или s3
STORAGE_TYPE=filetree

# Абсолютный путь к папке плагина dynmap (необходим для чтения json конфигов/обновлений и файлов)
DYNMAP_DIR=/home/minecraft/plugins/dynmap

# Настройки базы данных (требуются, если STORAGE_TYPE=db или используется база данных для авторизации)
DB_TYPE=mysql # mysql, mariadb или postgres
DB_HOST=localhost
DB_PORT=3306
DB_USER=dynmap
DB_PASSWORD=secret_password
DB_NAME=dynmap
DB_PREFIX=dynmap_

# Настройки S3-совместимого хранилища (требуются, если STORAGE_TYPE=s3)
S3_ENDPOINT=https://s3.us-west-2.amazonaws.com
S3_REGION=us-west-2
S3_BUCKET=my-dynmap-tiles
S3_ACCESS_KEY_ID=your_access_key
S3_SECRET_ACCESS_KEY=your_secret_key
S3_PATH_PREFIX=tiles/
```

## Сборка и запуск

### Требования
* Node.js (v18+)
* Yarn (версия 4 используется в проекте)

### 1. Установка зависимостей
Установите необходимые пакеты в корневой папке проекта:
```bash
yarn install
```

### 2. Сборка фронтенда и бэкенда
Для сборки статических файлов карты и компиляции TypeScript-сервера запустите:
```bash
yarn run build
```
Эта команда очистит старые сборки, скомпилирует фронтенд в папку `dist`, соберет Java-плагин (если требуется) и скомпилирует бэкенд в `backend/dist`.

### 3. Запуск сервера в режиме разработки (Dev)
```bash
yarn run backend:dev
```

### 4. Запуск в продакшене (Production)
```bash
yarn run backend:start
```
Сервер будет доступен по адресу `http://localhost:8082` (или по указанному в `PORT` порту).
